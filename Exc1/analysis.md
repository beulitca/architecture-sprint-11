## Пояснения к диаграмме
Сохраняем DWH, чтобы не переделывать интерфейсы
Мигрируем данные в LakeHouse - настраиваем CDC
Emmiter - обрабатывает события поступающие в систему, публикует их в Кафка LakeHous
Ingestion - обрабатывает запросы данных по API
Бизнес-подразделения получают данные золотых карточек
ИИ обрабатывает сырые данные
Остальные компоненты стандартны для LakeHous

------------
Центр данных самообслуживания (портал витрин) : единая точка для определения датасетов, построения отчётов, доступа к семантическому слою; авторизация через Keycloak (SSO) .

Lakehouse-платформа : объектное хранилище + открытый табличный формат Apache Iceberg, пакетная/потоковая обработка Airflow + Spark

Продукты доменных данных : обработка данных на уровне доменов: Бухгалтерия, финансы, Медицина, Сотрудники.   

Событийно-ориентированные системы :  CDC (Debezium) для онлайновых систем; старая шина Camel 

Управление и безопасность : централизованная политика доступа (безопасность на уровне строк/столбцов, маскирование, ABAC/RBAC), прозрачные PHI/медкарты/исследования не рассматриваются в витрине ; в аналитическую платформу поступают только деидентифицированные агрегаты через сервис Spark .

## Приоритизация (MoSCoW)

# Must:
Развернуть Lakehouse-платформу (хранение+обработка+обслуживание) и каталог данных с линиями.
Ввести продукты данных домена + контракты данных (владельцы, SLA).
Поднять CDC-инжест из ключевых источников (финтех, операционные БД).
Построить портал самообслуживания на витринном слое семантического слоя (доступ по роликам).
Включить управление и безопасность : единый вход (Keycloak), маска строки/столбца, деидентификация для PHI.
Ввести Качество данных в пайплайнах (ворота качества).

#  Should:
Консолидация метрики (хранилище показателей/семантический уровень), единый словарь показателей.
Автонаблюдаемость пайплайнов (метрики, алерты, lineage-drift).
Перенос критических отчетов из PowerBuilder/legacy BI.

# Could:
Golden Record для клиентов/контрагентов.
Магазин функций для ML-кейсов финтеха.
Реалтайм-витрины (ClickHouse/Materialized Views) для интерактива < секунд.

# Will not:
Универсальная шина только на Camel — вместо этого мигрируем на события/API.
